What is checked

The game folder has dvdroot_ps4 and sce_sys/param.sfo at version 01.09 (or an update folder beside it).
The eboot's SHA-256 is the 1.09 eboot's.
A wrong folder says what to pick instead; a version other than 1.09 is a warning, not a stop.
